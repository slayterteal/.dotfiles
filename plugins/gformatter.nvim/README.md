GFormatter


# Introduction

GFormatter exists to implement several handly tools to help abide by Garmin's code standards (largely for matting ones).

# Installation

Lazy.nvim install
```
return {
  dir = "C:/Users/<you>/dev/gformatter.nvim",
  name = "gformatter.nvim",
  config = function()
    require("gformatter").setup({})
  end,
},
```
